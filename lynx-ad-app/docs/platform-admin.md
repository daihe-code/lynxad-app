# 灵投平台账户管理后台

## 入口与权限

- 管理员登录：`/admin/login`；管理控制台：`/admin`。
- 管理员账户保存在 `platform_admin_account`，与普通灵投用户独立。普通用户注册、店主权限和企业管理员权限均不会获得平台管理员权限。
- `/api/v1/admin/**` 由 `AdminAccessConfiguration` 统一拦截，仅登录接口公开。访问必须同时具备签名 JWT 中的 ADMIN 身份、有效的平台管理员账户和未撤销的数据库会话。
- 管理会话最长 2 小时；退出撤销当前会话，修改密码撤销全部会话。连续 5 次密码错误后暂时锁定 10 分钟。
- 前端管理员 token 使用 `sessionStorage` 的 `lynx.admin.token`，与普通用户 `localStorage` 的 `lynx.token` 分开。管理员退出或失效不会退出普通用户账号。
- 普通用户导航不展示管理入口；后台并不依赖隐藏链接作为权限保护。

## 用户资料和日志

控制台提供注册用户列表、详情抽屉、登录日志、套餐延期记录、管理员操作日志，以及注册用户数、账户数、有效套餐数、试用账户数、当日成功登录次数。

用户列表支持手机号、姓名、公司、灵投账户和用户 ID 搜索，以及套餐状态筛选。详情展示联系方式、注册时间、企业资料、账户归属、账户成员数、广告账户及计划数量、试用与正式套餐到期时间、套餐来源和续费设置。接口只返回是否设置密码的布尔值，不返回密码哈希或广告账户令牌。

`user_login_record` 记录密码、短信登录的成功及失败、时间、IP、浏览器信息。失败日志在原登录事务回滚后写入，不保存密码、验证码或登录令牌。V32 将已有 `audit_record` 中的 LOGIN 记录迁入历史日志，方法标记为 LEGACY；旧审计记录保留，新成功日志不会重复查询两份来源。更早没有记录的登录无法补回。日志日期筛选使用北京时间。

## 手动延长套餐

在用户详情中点击“延长套餐”，选择试用或正式套餐、延长天数并填写原因。支持 7、30、90、365 天快捷选项及 1 至 3650 天自定义时长。页面显示原到期时间和预计新到期时间。

套餐归属于灵投账户（tenant），同一账户的所有成员共享权益。界面显示账户和成员数量，延期记录也按整个账户查询。未建立账户或归属不明确的用户不能直接延期。

- 未到期：新到期时间为原到期时间加延长天数。
- 已到期或尚未开通：以实际提交时间为起点加延长天数。
- 已有有效正式套餐时，延长正式套餐；不允许通过延长试用替代正式套餐。
- 已有正式套餐延期保持原套餐类型、付款事实、自动续费设置和待降级设置，仅更新有效期与相应状态。
- 尚无正式套餐时，管理员可选择套餐类型人工开通。来源为 ADMIN，自动续费关闭，实付金额为 0，不伪造支付订单。
- 存在 PENDING_PAY 套餐订单时，先处理订单再延期，避免未完成支付随后覆盖人工授权。

接口 `POST /api/v1/admin/users/{id}/package/extend` 接收 `requestId`（UUID）、`type`（TRIAL/SUBSCRIPTION）、`planCode`、`days`、`expectedEnd` 和 `reason`。已有套餐的 `expectedEnd` 必须与当前到期时间一致，无套餐为 null；过期快照返回冲突，需要刷新资料。

一次操作中的套餐更新、`platform_package_adjustment` 台账和管理员审计在同一事务提交。同一管理员、相同 requestId 和请求内容重试会返回原台账，不重复加天数。重用请求标识但改变内容会被拒绝。前端在提交结果不确定时保留原 requestId，修改表单后生成新标识。

延期事务使用 READ_COMMITTED 并锁定 `sys_tenant`，再核查成员归属、读取延期收据和套餐。正式套餐支付、修改续费设置、过期状态结算通过 `MpSubscriptionRepository` 在事务中取得同一账户锁并读取当前订阅，防止旧订阅对象覆盖管理员刚更新的有效期。共享数据库锁适用于多服务实例。

## 首个管理员配置

V32 同时提供 MySQL 和 PostgreSQL 迁移。初始管理员由服务端启动流程配置，只在尚无管理员且同时提供以下两项时创建：

```properties
lynx.ad.admin.bootstrap-username=your-admin-name
lynx.ad.admin.bootstrap-password=<由部署人员安全提供的初始密码>
```

登录名为 3 至 64 位字母、数字或 `_.@-`。密码至少 12 个字符、最多 72 个 UTF-8 字节，并包含字母和数字。没有默认密码，数据库仅保存 BCrypt 哈希。初始化后删除配置中的密码；重启不应覆盖已有账号。配置及初始凭据文件放在仓库之外，并限制文件访问。

当前本机测试账号为 `platform-admin`，初始登录信息位于 `D:/LynxAd-runtime/platform-admin-20261013/管理员初始登录信息.txt`，仅当前 Windows 用户和 SYSTEM 可访问。该文件只记录初始密码，管理员通过后台改密后不会同步更新文件。管理后台无公开注册、短信找回或普通用户提升权限接口。

## 接口

| 方法 | `/api/v1/admin` 下的路径 | 用途 |
| --- | --- | --- |
| POST | `/auth/login` | 独立管理员登录 |
| GET | `/auth/me` | 当前管理员 |
| POST | `/auth/logout` | 撤销当前管理会话 |
| POST | `/auth/password` | 修改密码并撤销全部管理会话 |
| GET | `/overview` | 账户概览 |
| GET | `/users` | 用户搜索和分页 |
| GET | `/users/{id}` | 用户、账户与套餐详情 |
| GET | `/login-logs` | 用户登录历史 |
| POST | `/users/{id}/package/extend` | 手动延期或开通 |
| GET | `/package-adjustments` | 人工授权历史 |
| GET | `/audit-logs` | 管理员操作审计 |
